# Depression EDA

This folder contains the completed descriptive EDA for the depression-only project focus. It covers the Beck outcome, candidate background and phone-use predictors, app-selection responses, and phone-dependence questionnaire items. It does not claim causation or statistical significance.

## Contents

- `preliminary_eda_findings.md` — plain-language findings, limitations, and presentation takeaway.
- `generate_eda.py` — reads the source workbooks and regenerates the EDA tables and four extended charts directly in the presentation folder without editing source data.
- `requirements-eda.txt` — Python packages needed to run the script.
- `figures/presentation/` — the single canonical set of 10 charts. The four extended charts are regenerated by the script; the first six are retained from the initial EDA.
- `tables/` — six CSVs: data inventory, Beck score bands, candidate feature profiles, group comparisons, associations with Beck total, and data-quality review.

## Regenerate the EDA tables and extended charts

From the project root:

```bash
python -m pip install -r analysis/eda/requirements-eda.txt
python analysis/eda/generate_eda.py
```

The script reads the three source workbooks under `Digital Sedentary Behavior, Mobile Device Dependen/`. It requires unique matching student codes and stops if the files do not align. It writes derived totals and summaries only to the EDA folder. Original workbooks remain unchanged.

## Interpretation notes

The project-defined target is Beck total >=11, combining the 11–16 mild mood-disturbance band with every higher band. Confirm that the Beck form and scoring guide match before presenting this as a depression classification. Phone-dependence totals used in comparisons are recomputed from the 22 item responses because one supplied total is inconsistent. Small category counts are shown in the charts and tables and should be considered before interpretation.
